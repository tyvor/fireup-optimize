# Как добавить язык в FireUp

Один JSON-файл в `locales/` задаёт название языка в настройках, перевод интерфейса и описание расширения в Firefox. JavaScript менять не нужно.

1. Скопируйте [locales/en.json](../locales/en.json) в новый файл, например `locales/fr.json` или `locales/pt-BR.json`. Имя файла должно быть каноническим тегом языка.
2. В поле `name` напишите название языка на нём самом. Переведите `description`. Для направления справа налево установите `"direction": "rtl"`.
3. В `messages` переводите значения справа от двоеточия. Оставляйте английские ключи слева и имена подстановок, например `{count}` и `{title}`. Подстановку можно перенести в другое место фразы. Удалите ещё не переведённые значения, если хотите временно использовать запасной перевод. Ключи, которых пока нет в переводе, подставляются из родственного базового языка, если он есть, либо из английского.
4. Запустите `npm run locales`, затем `npm run check:source` и `npm test`. Генератор обновит `extension/locales.generated.js` и нативные файлы `extension/_locales/`. Эти файлы входят в XPI.
5. Загрузите расширение временно в Firefox и выберите новый язык в «Настройки → Оформление и язык». После сохранения проверьте панель, контекстное меню вкладок и описание горячей клавиши. Описание дополнения в менеджере выбирает Firefox по своему языку.

Генератор проверяет незнакомые ключи и подстановки. Для публикации переведите весь каталог и проверьте реальные строки в узкой панели. Запуск сборки требует Node.js 22 или новее. Скачивать пакеты для генерации языка не требуется.

Пример частичного каталога для проверки (французский перевод не входит в сборку):

```json
{
  "name": "Français",
  "direction": "ltr",
  "description": "Met en veille les onglets Firefox inactifs.",
  "messages": {
    "Settings": "Paramètres",
    "Show candidates ({count})": "Afficher les onglets concernés ({count})"
  }
}
```

Формат браузерных каталогов описан в [документации Mozilla](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Internationalization).
