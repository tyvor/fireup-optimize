# Разрешения

| Разрешение | Для чего FireUp его использует |
| --- | --- |
| `tabs` | Получает названия и адреса открытых вкладок, показывает их в панели, проверяет домены-исключения и смену адреса перед выгрузкой. |
| `storage` | Сохраняет настройки локально и временное рабочее состояние до завершения браузера. |
| `alarms` | Запускает проверку автосна, продолжает очередь и учитывает окончание временной защиты. |
| `menus` | Добавляет команды защиты и выгрузки в контекстное меню вкладки. |
| `sessions` | Сохраняет защиту отдельной вкладки через API сессий Firefox. |

Разрешение `tabs` даёт доступ к чувствительным сведениям о вкладках. FireUp использует их локально по правилам [PRIVACY.md](../PRIVACY.md). Дополнение не запрашивает разрешения на чтение содержимого сайтов, `history`, `cookies` или `webRequest`.

В манифесте указано отсутствие сбора данных: `data_collection_permissions.required: ["none"]`. Это означает отсутствие передачи данных разработчику, а не отсутствие локальной обработки адресов вкладок.
